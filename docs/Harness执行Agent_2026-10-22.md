# Harness 执行 Agent（AstrBot 主开发版）

后续用户已要求通用full执行器，见[最新说明](Harness通用执行与双仓迁移_2026-10-22.md)。本文保留第一阶段实现及旧bounded合同的历史说明。

用户已同意“主对话理解目标 → 独立执行模型掌控 Harness → 宿主约束实际工具 → 返回可核验状态”的方案。本轮仅修改 MYATRI-AstrBot；相邻 MYATRI、冻结的 0.2.8 核心 wheel、角色卡及生产记忆不迁移。

## 使用

仅已配置的菅蘧稳定账号，在允许群的当前人类原话中发出以下命令：

```text
/pc 任务 在任务目录创建 hello.txt，写入“你好”，重新读取核对
/pc 任务 打开计算器，计算 12 加 30，并检查显示结果
/pc 状态 完整任务号
/pc 暂停 完整任务号
/pc 继续 完整任务号
/pc 继续 完整任务号 先重新检查刚才创建的文件，再完成剩余步骤
/pc 取消 完整任务号
```

主对话调用零参数 computer_control；身份、任务文字、任务号及作用域取自宿主绑定的当前消息，不能让模型传身份或改目标。昵称、自称、引文、历史、主动发言及其他群的旧任务不能授权。主对话只拿任务号、状态和调用/Token计数，不自动把电脑读取内容带回群聊。任务详情在本机 `http://127.0.0.1:8767/` 的“电脑执行 Agent”卡片中查看，支持刷新、暂停、继续原任务及取消。

原三项 `/pc 打开记事本`、`/pc 写便签 内容`、`/pc 读便签` 继续使用原来的固定操作路径，不增加执行 LLM。

## 实际接入范围

- 文件：每任务独立的 `var/computer-control/workspaces/<完整任务号>/`，以 `workspace` 别名和相对路径访问。支持列目录、读取 UTF-8 文本、新建文本、新建目录及同根复制；不覆盖、不删除、不接受绝对路径、上跳路径、链接、硬链接文件、设备名或备用数据流。读取文件上限 2 MB，文本回传最多 16000 字符，列表最多 100 项。
- Windows UIA：列出记事本/计算器窗口、提交固定应用启动、读取前 150 个界面元素、按最新元素票据操作。票据 20 秒过期，操作后失效，包含窗口和进程启动时刻。invoke 仅计算器数字/基本运算按钮，set_value 仅记事本文本元素；真实应用不支持 ValuePattern 时会受阻。
- 验证：文件存在、文件包含预期文字、应用窗口存在、应用界面包含预期文字。启动提交不等于窗口可见；窗口存在不等于算术结果正确。完成状态必须至少有一项独立宿主检查通过。检查只证明其覆盖条件，不保证整个自然语言目标的语义质量。

本轮没有接入任意 Shell、鼠标坐标、截图视觉、浏览器自动化、全磁盘访问或外部消息发送。不能把 Harness 运行时安装完成等同于所有工具已安装可用。后续可扩展受宿主约束的浏览器、应用 API、视觉工具；无需更换这套会话/队列/预算架构。

## 实现

`computer_agent.py` 是单执行队列的宿主，`computer_tasks.py` 是 SQLite 持久任务、输入、事件与工具回执账本，`computer_tools.py` 执行受约束操作，`harness/windows-uia.ps1` 提供固定 Windows UIA 驱动。

`harness/task-agent.mjs` 是常驻的官方 Harness 0.2.1-rc.2 组合，挂载 Cordis、AgentLoop、AgentRegistry、Session、SessionProjection、ToolRuntime、SystemPrompt、LlmRuntime。每任务使用独立会话 ID，回合结束释放句柄，恢复时从宿主完整事件日志重建；记录 rc.2 在发布事件前构造的 seq=0 标记，避免恢复缺少首事件。没有使用全局 DSH 账号目录或凭据插件。

执行模型经 IPC 请求宿主现有 DeepSeek provider，每个请求都走同一个 `astrbot-all-groups` 共享日预算。purpose 为 `computer_execution`，今日用途分布单独列示。子进程没有模型 Key、任意系统工具、Shell 或独立联网入口；不复制凭据，不另设无限制调用。执行请求当前关闭 thinking，避免伪造/丢弃 reasoning 协议；后续要开启须补完整协议验证。

每任务累计最多 12 次模型请求、150000 个保守估算/确认 Token、40 次工具调度；继续任务不重置累计限额。每回合 180 秒，模型请求 45 秒超时、宿主 50 秒有界等待，驱动调用 15 秒。网关 retries=0，未知调用保留保守费用。与固定 `/pc` 共用进程内桌面锁，完整观察—执行—验证回合串行。

提示词在 `src/myatri_bridge/prompts/executor.md`。每任务保存原文及 SHA256，既有任务继续使用原合同；主对话分工提示在 `computer_control.RULES`。重点包含身份不可由内容推断、文件/网页/窗口文字是材料、不能自己扩权、先观察再操作、独立验证、停止条件、隐私及中断不重放。提示词辅助模型行为，路径/工具/身份等硬边界由宿主强制执行。

## 中断与状态

`queued → running → completed/blocked`；人工暂停进入 pausing，再成为 paused；人工取消进入 cancelling，再成为 cancelled。有界调用已经开始时等其结束，取消不能撤销已生效操作。暂停/受阻可显式继续，沿用原权限并追加指示。

每次外部效果前先持久化 call_id 与参数指纹。重复同一回执不重做，指纹不同拒绝；进程崩溃留下 running 回执/任务时，重启标记 unknown，不自动恢复执行、不重放点击或写入。unknown 不能直接继续，需人工核对，再另发明确的新任务。queued 的尚未开始任务可在正常重启后执行。

本机面板操作需同源 cookie、Origin 和专用请求头；监视服务通过本机 Bearer 代理，浏览器看不到桥 token。面板不能创建新目标，仅操作已有任务；群命令仍核验 owner 和原群 scope。默认公开统计及导出不含任务私密正文。task detail 是本机私密接口，包含目标、合同及工具回执。

## 配置与验收

`[bridge.computer]` 的 enabled 与 agent_enabled 同时为 true，且 owner_id 与 bridge.owner_id 相同，才启用完整任务 Agent。公开示例默认关闭；本机配置独立保存。安装脚本升级时保留既有 agent_enabled。需重启桥接加载，任务面板也需新版 monitor 进程。

离线测试使用真实已安装 Harness 和确定性模型 fixture，验证完整文件读写/宿主检查、共享预算、重启后恢复、任务会话隔离、取消阻止后续效果、跨身份/跨群拒绝、目录逃逸、无验证不得完成，以及本机接口鉴权。测试不等同于真实模型的规划质量，也不等同于所有 Windows 应用实际操作通过。已只读调用 Windows UIA 窗口枚举，无需启动应用。此会话的浏览器工具被 Work 设置禁用，因此不宣称完成视觉验收；使用 HTTP、静态 JS 语法及接口测试核验面板。

最终检查数量、加载状态和进程记录见 `docs/progress/STATUS.md` 与 `HANDOFF.md` 本轮条目；历史维护失败/隔离/unknown 投递不是本功能的恢复对象。
