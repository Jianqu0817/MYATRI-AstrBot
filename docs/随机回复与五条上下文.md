# 群聊随机回复与近期上下文

指定白名单群的新文字消息按0.05概率触发；出现“小温暖”“小溫暖”、@机器人或原/warm命令时直接触发。随机触发沿用8秒冷却，关键词及@不受此冷却限制。抽取使用消息ID的均匀哈希，重试不会重新抽取；同一消息不会重复发送。

未触发的消息只更新本地滚动缓存，不调用LLM。每群保留最近最多20条群消息（含触发消息与发送接口确认成功的机器人回复），保留成员ID、昵称、时间和原文；自身消息不参与触发。模型的近期对话窗口使用这个信封，角色设定、长期记忆和已授权导入的历史继续加载。旧对话及记忆不删除。

概率可在config/bridge.local.toml的[bridge]下设置random_reply_probability，缺省0.05。插件文件已复制到本机AstrBot运行目录。关闭当前机器人服务窗口，再运行Start-WeChat-Live.cmd加载；微信无需退出。

34项离线测试通过，包含概率开关、关键词、五条窗口、去重、冷却及实际AstrBot插件本地联调。没有发送微信测试消息或调用付费模型。此次没有修改角色卡，也没有执行Git提交或GitHub同步。
