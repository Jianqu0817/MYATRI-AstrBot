## 一并发布的既有改动

- 上下文窗口：群完整往返80轮、近期100条（可配置），共享200k工作上限；召回、摘要与继承材料预算放宽，但不填充无关历史。
- 提示词：当前原话/澄清/可靠引用优先；背景不是待办列表，记忆可隐性使用，默认只接一个相关话头，说到位就停。明确要求总结、回忆或多个问题时按要求展开。对已确认创作者可轻微依恋，普通群友不套用关系。
- JSON：去重复渠道/成员字段、空值与本地排序分数，保留原话、成员ID/昵称、时间、引用、证据关系和读取进度。
- 查看器：View-Context.cmd的8768展示真实请求副本，Monitor-Context.cmd的8767展示用量与诊断；历史快照与最新捕获分开。旧后台不含runtime_controls时给出明确重启提示。
- 分段发送：同次生成用<|msg|>标记2—3段；<=15字一条，没有自然断点时保留一条。插件按群顺序发送并逐段确认，失败/中断结果不明时停止，保存进度且不自动重发，整体仍计一轮。
- 控制按钮：运行中微信群可重载角色卡/系统提示词、清空工作窗口。清窗持久化快照与旁听边界，保留原始记录、长期记忆和人格；旧摘要与中断协议不自动重新塞入。私聊没有HTTP控制通道，按钮禁用。
