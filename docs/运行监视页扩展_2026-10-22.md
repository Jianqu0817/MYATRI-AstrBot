# AstrBot 运行监视页扩展

后续同日更新：新增本机“回复概率与自动恢复”设置窗口。下文“只读”指原有统计接口；新增设置走原桥接鉴权与同源会话保护。见[告警诊断与动态概率](告警诊断与动态概率_2026-10-22.md)。

入口仍为 `Monitor-Context.cmd` → <http://127.0.0.1:8767/>。只读页面，无模型调用、消息发送、记忆修复或电脑操作接口。若监视后台是旧进程，须关闭其终端再打开入口，仅刷新网页不能更新 Python 后台。无需为此重启微信机器人。

原8768上下文查看页也加入监视页跳转入口。此次已单独启动新版8767监视服务；没有重启微信桥接或8768控制服务。

## 展示内容

- 今日 API 确认输入、输出、总 Token，请求尝试数、失败与用量未确认次数。
- 主对话（包括每次工具往返）、摘要、情绪、经历提炼等用途分布；北京时间24小时柱状图。
- 每个群的记忆类型计数、最近入档时间、存档投影与索引指针是否对应最新归档。
- 即时情绪、缓慢心境的 PAD 数值；生效事件、撤回记录、未结关切与未来事件计数。
- 原有单次上下文、压缩阈值、最近回复耗时、上下文构成、共享日额度、旁听摘要与健康告警。
- 后台维护任务的等待、运行、成功、重试、延后、提案和失败状态，以及运行任务的过期/缺失租约数。
- 暂停/恢复刷新，导出当前白名单统计 JSON；展开的记忆详情在自动刷新时保留。

## 统计口径与限制

“今日”是北京时间00:00至24:00，按模型请求日志的 `recorded_at` 归日，即请求结束记账时间；不是请求开始时间。累计扫描所有usage记录，不受旧页面最近2000条窗口限制。接受 API 已返回的非负整数输入与输出；两者缺失或调用未确认时不猜测消耗。重试、工具后续调用是独立尝试，分别计入。缓存已在输入内、推理已在输出内，不再重复加到总量中。分项缓存/推理只合计 API 实际提供的字段，不保证覆盖全部请求。

没有时区的旧日志不能可靠归日，单列未归日条数；数据库不可读显示部分可读/暂时不可读。不是完整供应商账单，不覆盖其他程序、账号下其他调用或未落盘日志。搜索使用独立次数账本，本页不将它虚构为模型 Token。配置中的0价格也不解释为免费。

原“共享日额度”沿用 UTC 日（北京时间08:00重置），其保守结算、未知请求收费预估与在途预留继续单列。不能拿它与自然日 API 确认总量直接对齐。

记忆计数取 `domains/*/projection.sqlite3` 中每个逻辑ID的最新版本，不把历史修订重复计数；只输出固定类别。投影/索引的新旧状态是水位比较，不是完整性、召回效果或记忆语义质量验收。投影按配置批量发布，落后不自动表示故障，也不会为看板触发重建。多个隔离域无法唯一判定时显示待核对。

情绪复用冻结核心0.2.8的 `EmotionState.read`，以同一只读投影快照计算时间衰减、撤回排除与关切计数。它可能落后于运行时最新归档；不是直接读取另一个进程内存。没有评价时标注配置基线，关闭模块与暂时不可读分别显示。PAD愉悦度范围−1～1，唤醒度/掌控感0～1；是角色工程模拟，不是用户心理测量，也不意味着人格变更。

任务数量取持久账本；“running”不保证进程仍活着，租约过期只报告而不接管。历史失败、隔离和待核候选告警原样显示，不因加页面而重试或消除。

## 刷新、安全与范围

轻量请求/健康指标每2秒刷新；每日累计、记忆、情绪和任务每15秒采样并显示时间。情绪随采样时间重新衰减。SQLite只读URI、query_only与固定配置路径；不构造会恢复/写入的ArchiveStore/MemoryIndex，不读取原始消息正文，情绪评价载荷仅在本机计算，API不返回评价文本、引用、消息、账号ID、密钥或推理文本。原有loopback、Host、Origin、跨站和GET限制保留。

只统计本AstrBot仓库的群运行库，移除旧监视页对相邻MYATRI私聊库的合并读取。没有改相邻仓库、vendor、角色卡、消息链路、摘要频率、记忆格式或电脑控制授权。

## 验证

见 `tests/test_monitor_stats.py`、既有上下文监视与健康测试：跨北京时间零点/不同偏移时区、超2000请求、未知用量、缓存/推理不重复加算、最新记忆版本、负PAD/衰减/撤回、缺失/损坏库、租约过期、只读无写入、敏感数据过滤、相邻CLI隔离及HTTP跨站限制。

浏览器检查了真实本机只读面板、暂停/恢复、导出与记忆详情展开。生产数据采样只读取统计与情绪投影，没有付费调用、群发送或记忆修复。最终测试结果记入 `docs/progress/STATUS.md` 顶部。
