# WeChatAgent 接入与启动

2026-10-21，当前桥接版本0.1.2，使用核心0.1.8、角色卡1.3。私聊记忆迁入当前群的范围见[日常口语与记忆迁移](日常口语与记忆迁移_0.1.2.md)。

## 本机已准备

已从 sourcepro5/WeChatAgent 0.3.9 发布页取得安装包，核对发布方 SHA256，解包至本项目 `var/`。没有运行安装器，没有覆盖系统中原先安装的微信。配套客户端固定为 4.1.10.27，腾讯签名有效；不能把它的 Hook 装进 4.1.15.13。

独立程序在 `var/wechatagent-runtime/workspace/state/hook/wechat-4.1.10.27/`；Python、Node、发送 DLL 和读取 DLL 也在 `var/`。原作者代码、许可与来源说明保留在本地运行目录，不作为本仓库源码提交。配置的目标群名和机器人昵称仅保存在被 Git 忽略的 `config/wechatagent.local.toml`。

本机已经由用户完成配套微信登录。读取凭据用 Windows 当前用户 DPAPI 加密，已唯一绑定测试群的真实 `@chatroom` ID 与当前机器人账号。0.1.2已按用户新授权迁入原私聊的冻结历史，保留来源和成员身份边界；其他群不自动共享。配置脚本只写本项目的运行数据；配套微信登录后仍使用微信自己的账号数据目录，不能声称它创建了完全独立的聊天数据库副本。

## 日常启动

1. 保持配套微信已登录。以后需要重新打开时，先从托盘退出其他桌面微信，再双击项目根目录 `Open-WeChat.cmd`，自己扫码或在手机上确认。不能只扫描二维码而遗漏手机确认。
2. 首次读取配置已经完成；读取密钥失效时，双击 `Setup-WeChat.cmd`，按提示在配套微信里退出账号再登录。脚本核验账号后加密保存凭据，不打印密钥。多个候选账号由密钥认证和发送端实际账号确定，不按目录修改时间猜测。
3. 双击 `Start-WeChat.cmd` 启动读取服务、小温暖后端和 AstrBot。它沿用当前 `bridge.local.toml` 的模式；本次交付保留 `offline`，因此尚不会调用模型。此模式在群里触发时会发送离线演示回复。
4. 真正与小温暖聊天时，改用 `Start-WeChat-Live.cmd`。这是显式选择真实模型模式，会沿用已有 Windows 模型凭据；无需再次填写 API Key。只处理启动后的新消息，不补发测试阶段的旧消息。
5. 由其他群成员 `@机器人昵称 内容` 或发送 `/warm 内容`。机器人账号自己发送的消息不会触发回复。当前只处理文字，4000 字及以上的入站文字被拒绝，以免将上游截断的消息当作完整记忆。

两个启动入口不能同时运行。关闭启动窗口或 Ctrl+C 会停止它创建的读取服务和后端；配套微信保持运行。控制台若提示端口占用，应先关闭旧服务，不要重复双击。

`Check-WeChat.cmd` 只检查现有服务的账号、版本和绑定，不启动读取服务。未启动读取服务时会报告本机后端不可达。窗口报错会保留，不会一闪而过。

## 启动时自动处理

- 校验 native/read 两端都是同一个账号；账号、版本不符时拒绝启用。
- 把唯一真实群 ID 同步到桥接后端和插件白名单，固定平台实例 `xiaowennuan-wechat`。
- 关闭 AstrBot 内置 LLM，继续由 MYATRI 生成人格与记忆回复。
- 这个专用入口保留面板里其他平台的配置，但将其 `enable` 置为 false，避免一起连接无关的 QQ/ClawBot。原配置保存在 `var/setup-backups/`，可以在面板中自行重新启用；不建议与专用入口混用。
- 读取端只选目标群，私聊白名单为空。未开启上游 DSH、上游模型、表情收集、主动聊天、联网搜索或上下文压缩服务。

## 实现与限制

新平台注册在插件中：`wechatagent_platform.py`；HTTP 客户端为 `wechatagent_client.py`。它直接消费上游认证的 SSE `/api/v1/push/messages`，使用真实账号、群 ID、成员 ID 与消息 ID，不采用上游将群名或成员 ID 映射为短数字的 OneBot 路径。

正文中的 `@昵称` 是显式文字唤醒标记，并非已经认证的微信 At 成员对象；也支持 `/warm `。昵称不用于判断发言者身份或记忆归属。

发送前再次检查账号，先领取 MYATRI 持久化发送任务，再调用 `/SendTextMsg`。只有出现新的匹配发出记录和正数服务器消息 ID 后才记 `sent`。读取端 `isSend` 的布尔值及整数 0/1 已兼容。异常或超时记 `unknown`，不自动重发，也不把服务器记录当作对方已读。

后台群记忆、维护频率和 50M Token 日账本仍由 MYATRI 控制。普通用户消息不能修改群白名单、人格配置或工具权限。群记忆与原命令行私聊库分开，原来的 ATRI/小温暖私聊档案保持原处。

## 验证范围

本地模拟覆盖错误版本、错误账号、多账号、重名群、稳定群 ID、文字唤醒、原始时间、回执整数类型、发送超时不重提、回环鉴权地址、真正 AstrBot 插件和后端的模拟联调。

本机验证包括：发布包文件哈希、配套微信签名、Python 读取依赖、用户本人登录、真实账号一致性、目标群唯一绑定、读取端健康状态、群友新发 @ 消息读取、AstrBot 实际加载此平台。真实发送和付费模型回复另行验证，不包含在上述成功结论中。`MYATRI_WECHAT_OBSERVE_ONLY=1` 可启动只观察模式，在平台层阻止事件进入模型管线。

本机检查记录在 `var/wechatagent-readiness.json` 与 `var/wechatagent-validation.json`，不提交账号或群的私有数据。
